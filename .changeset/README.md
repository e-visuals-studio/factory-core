# Changesets

Vsak PR, ki spremeni `@e-visuals-studio/core`, doda changeset: `pnpm changeset` (izbereš semver korak in na kratko opišeš spremembo v slovenščini).

Ob izdaji `pnpm changeset version` dvigne verzijo v `packages/core/package.json` in zapiše `packages/core/CHANGELOG.md`; nato tag `vX.Y.Z` (glej README, Distribucija).
